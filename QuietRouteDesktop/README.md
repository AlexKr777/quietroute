# Тихий маршрут — приложение для Windows

Это отдельная desktop-оболочка со своей сборкой сцены. Исходники сайта остаются в корне проекта и продолжают независимо запускаться через `START_SITE.bat`: изменения приложения их не перезаписывают.

## Открыть приложение

Дважды нажмите `START_APP.bat` в корне проекта. Если portable-сборка уже существует, откроется готовый EXE. Иначе скрипт установит зависимости, соберёт сайт и запустит приложение из исходников.

## Управление окном

- `поверх` — держать окно поверх остальных окон;
- `мини` — компактное окно 480×360 в правом нижнем углу, приподнятое над всплывающей панелью Windows; при переходе оно само включает режим `поверх`, который при желании можно отключить;
- `Ctrl+Shift+P` — переключить режим поверх окон;
- `Ctrl+Shift+M` — переключить обычный и компактный размер;
- верхнюю полосу можно перетаскивать мышью.

Текущее локальное время показывается поверх самой ночной сцены. При первом переходе в компактное окно микшер раскрыт, чтобы все каналы сразу были видны; при следующих переходах он начинается свёрнутым. Короткое нажатие на `звук` переключает оба состояния, а нажатие по свободному месту сцены закрывает раскрытый микшер. После закрытия компактная кнопка возвращается точно туда, где находилась до раскрытия. Чтобы переместить микшер, зажмите и потяните само слово `звук` или появляющиеся рядом три горизонтальные точки — это работает и в свёрнутом виде. Ползунок `всё` меняет общую громкость вплоть до полной тишины, не сдвигая настройки отдельных каналов.

Двойное нажатие на `музыка` переключает композицию. В приложении 33 спокойных инструментальных lo-fi/chill-hop трека от 1000 Handz и Ketsa; их громкость выровнена, а стартовые композиции выбираются без немедленных повторов между запусками. Дождь, мягкий ветер, птицы и далёкий гром сведены в отдельные ненавязчивые каналы. Все музыкальные записи, дождь и шрифт часов находятся только в приложении; сведения об их CC BY/CC0/OFL-лицензиях лежат в `assets/AUDIO_LICENSES.md` и `assets/FONT_LICENSES.md`.

## Собрать portable EXE

Дважды нажмите `BUILD_APP.bat` в корне проекта или выполните:

```powershell
cd QuietRouteDesktop
npm.cmd install
npm.cmd run package
```

Готовый файл: `QuietRouteDesktop\release\QuietRouteDesktop.exe`.
